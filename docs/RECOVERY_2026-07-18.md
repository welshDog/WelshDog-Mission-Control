1. **Your old admin UUID is dead.** `63df5bcb-9c5a-4b7b-992d-3e3e7b3295d9` belonged to the deleted project's `auth.users`. The new project has a **different UUID for you**. `requireAdmin` will 403 until the new one has `role = 'admin'`. This is the one most likely to eat an hour.

## Phase 2 — Your admin row (3 min) 🛡️

**This is the step that bites.** New project, new UUID.

```sql
-- 1. find your NEW auth user id
select id, email, created_at from auth.users order by created_at desc limit 10;

-- 2. does a public.users row already exist for it?

```

- **Row exists** → just promote it:
  ```sql

  ```

